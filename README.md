## ✨ 页面与功能

| 页面 | 文件 | 说明 |
| --- | --- | --- |
| 关于我们（首页） | `index.html` | 三屏人物幻灯片、优秀员工、员工之声 |
| 解决方案 | `solutions.html` | 装备横幅轮播 + 可滚动的商品列表 |
| 寻人启事 | `wanted.html` | 失联人员卡片、提交线索 |

### 主要特性

- **无限循环轮播**：首页与解决方案页的幻灯片滑到最后一张后，会继续向同一方向滑回第一张。
- **多种切换方式**：自动播放、点击圆点、鼠标拖拽、鼠标滚轮。
- **解决方案商城**：商品限购计数，点击「购买」后计数 +1，达到上限后按钮锁定（记录保存在浏览器 `localStorage`）。
- **寻人启事**：「提交线索」后按钮置灰锁定，并弹出集团风格的提示。
- **背景音乐播放器**：右上角音符按钮与悬浮歌单，自动读取 `music/` 目录，跨页面记忆曲目、进度、音量与播放模式。
- **移动端适配**：竖屏时提示横屏观看；横屏或点击页脚链接可切换为「电脑界面效果」。
- **控制台彩蛋**：打开浏览器开发者工具，每个页面都有一段集团风格的「安全协议」提示。
- **图片占位机制**：解决方案页的图片位在缺图时显示虚线占位框，放入同名图片后自动替换。

## 🎵 配置背景音乐

1. 把音乐文件放进 `music/` 目录（支持 `mp3`、`flac`、`wav`、`m4a`、`ogg`）。
2. 在每个页面 `</body>` 前引入播放器：

   ```html
   <script src="/assets/js/music-player.js" defer></script>
   ```

3. 如需修改歌单接口地址、默认音量等，编辑 `assets/js/music-player.js` 顶部的配置区：

   | 配置项 | 说明 |
   | --- | --- |
   | `API_URL` | 歌单接口地址，默认 `/music_list.php`，也可以填写其他站点的完整地址 |
   | `FALLBACK` | 接口请求失败时使用的备用歌单 |
   | `GAIN` | 音量缩放系数（0~1），嫌大就调小 |
   | `DEFAULT_LEVEL` | 首次访问时音量滑块的默认位置（0~1） |

## 🛠️ 自定义

- **商品信息**：在 `solutions.html` 中修改 `.item` 的名称、描述、价格与限购数（`data-max` 与「限购：x/y」）。
- **轮播内容**：修改 `.banner-slide` 内的标题、副标题与三个卖点；新增或减少幻灯片时，同步调整圆点按钮数量。
- **主题色**：各页面顶部 `:root` 中的 CSS 变量（`--navy`、`--blue-accent` 等）。
- **导航与页脚**：三个页面的头部、页脚结构一致，修改时请同步更新。
